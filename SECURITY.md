# Security policy

This policy covers the `recur` program (`bY4Yyya6CMHBUfU9BfgoWK8TCjVhWtxQPurtX56dF5v`) and the source in this repository.

## Reporting a vulnerability

Report privately, never in a public issue:

- GitHub: [open a private security advisory](https://github.com/rrLero/recur-program/security/advisories/new)
- Email: security@recurme.com

Include the affected instruction or account, the steps to reproduce, and the impact you expect. We reply within 72 hours and keep you updated until the fix ships.

## Scope

The program is on devnet and has not been audited yet; an audit comes before mainnet. Funds on devnet have no value, but we still want every report, because the same code goes to mainnet.

Out of scope: the Subscriptions program it builds on (report those to the [Solana Foundation](https://github.com/solana-foundation/subscriptions)), and denial of service on public RPC.

## Safe harbour

We won't take action against research done in good faith that stays on devnet or a local validator, avoids other users' accounts, and gives us reasonable time to fix before disclosure.
